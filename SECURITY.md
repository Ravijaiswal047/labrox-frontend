# Security Policy & Vulnerability Disclosure

## 21 CFR Part 11 & GxP Compliance Context
LabRox LIMS frontend is designed for clinical laboratories and diagnostic operations under FDA 21 CFR Part 11, HIPAA, and GAMP 5 standards. Strict session management, audit capture, and authorization integrity are enforced.

## Supported Versions
Only the latest release versions receive active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability in the LabRox frontend, **please DO NOT open a public issue**.

Instead, report vulnerabilities privately by emailing:
`security@labrox.io`

Include:
1. Description of the issue and affected pages/components.
2. Steps to reproduce or proof-of-concept.
3. Potential impact on patient privacy or clinical workflow security.

## Response & Disclosure Timeline
- **Initial Response:** Within 24 hours acknowledging receipt.
- **Triage & Remediation Plan:** Within 72 hours.
- **Fix & Advisory Release:** Coordinated disclosure after verified patch deployment.
