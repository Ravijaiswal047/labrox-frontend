## [0.1.0] - 2026-11-11

### Added
- React 18 single page application for LabRox New Gen Enterprise LIMS.
- Comprehensive role-based authentication and clinical session guard.
- Patient registration, investigation booking, and receipt billing module.
- Phlebotomy sample collection worklist with barcode validation.
- Sample Sorting (SRA) module with duplicate sort guards and audio cues.
- Department Receive module with status toggles (Received, Rejected, Hold).
- Clinical Result Entry with dynamic parameter entry, delta checks, and doctor approval flow.
- High-fidelity dispatch lab report viewer with A4 PDF preview and export.
- Quality Control dashboard with Levey-Jennings visual charts.
- Master data management for centers, departments, doctors, and test investigations.
